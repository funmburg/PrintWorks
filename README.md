# PrintWorks 0.3 для Windows

Распакуйте архив и запустите PrintWorks.exe. Программа использует локальные данные версии 0.1 из %LOCALAPPDATA%\PrintWorks. Переключатель ролей предназначен для демонстрации на одном компьютере.

## Плановое обслуживание

В роли «Ответственный» откройте «Плановое ТО». Для каждого станка можно задать период в днях, месяцах, моточасах или циклах. Старые даты ТО сохраняются. Начальный интервал составляет 30 дней. Проверка выполняется при запуске, после сохранения изменений и каждую минуту работы программы. За неделю и за день до календарного срока появляются напоминания. При наступлении срока или порога создаётся одна заявка. После приёмки следующая дата или порог отсчитываются от фактического выполнения.

## Аварии и ремонт

Создайте заявку с приоритетом «Авария». Станок на карте получит красный индикатор, а в роли «Руководитель» появится уведомление со ссылкой на заявку. Исполнитель берёт заявку и передаёт результат на приёмку. Ответственный может принять работу или вернуть её в ремонт с причиной.

## Запчасти

Взяв заявку, исполнитель запрашивает нужное количество деталей. Доступное количество резервируется. Недостающее количество видно в разделе «Склад». В роли «Закупки» укажите дату поставки каждой позиции. Исполнитель может перевести заявку в ожидание, указав причину. Кладовщик регистрирует поступления и выдачу. Когда весь комплект зарезервирован, ожидающая заявка возвращается в ремонт. Для передачи на приёмку все запрошенные детали должны быть выданы.

## Проверка и границы версии

В PowerShell запустите .\build.ps1 -Test для пересборки и самопроверки. Исполняемый файл включён в архив. Для сборки используется компилятор .NET Framework 4.x.


## Остатки из Excel

В роли «Кладовщик» откройте «Склад» и выберите «Подключить Excel с остатками». Для проверки приложена книга Пример-остатков.xlsx. Первая непустая строка первого листа должна содержать заголовки Артикул, Наименование и Остаток. Порядок колонок произвольный. Остаток указывается целым неотрицательным числом.

Файл считывается при подключении, при запуске приложения и каждую минуту, пока приложение открыто. Для обмена через общую папку выбирайте файл по постоянному пути. Повтор той же книги пропускается. Артикулы, отсутствующие в книге, сохраняют свои остатки. Чтобы обнулить позицию, укажите явный ноль. При расхождении с действующим резервом или ошибочной строке приложение показывает причину и сохраняет предыдущие остатки. Импортированный запас резервируется по ожидающим заявкам; после получения всего комплекта ремонт возобновляется.

## MAX

Для работы с ботом используйте Start-Max.cmd и инструкцию MAX-README.md. Сохраняются оба сценария — групповой чат и личные сообщения. Изображение Карта-цеха.png показывает интерфейс на демонстрационных данных.
