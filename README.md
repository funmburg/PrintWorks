# PrintWorks 0.3 для Windows

PrintWorks помогает типографии вести заявки на ремонт, видеть состояние станков на карте цеха, планировать ТО и учитывать запчасти. Заявку можно создать в приложении или отправить боту MAX из общего чата либо личных сообщений.

**[Скачать PrintWorks.exe для Windows](https://github.com/funmburg/PrintWorks/raw/refs/heads/main/PrintWorks.exe)** · [Скачать полный комплект ZIP](https://github.com/funmburg/PrintWorks/archive/refs/heads/main.zip)

## 1. Запустите приложение

1. Войдите в GitHub под аккаунтом с доступом к этому приватному репозиторию.
2. Для работы на одном компьютере скачайте и откройте `PrintWorks.exe`. Для работы с MAX или примером Excel скачайте ZIP, распакуйте его целиком и откройте папку с `PrintWorks.exe`.
3. Откроется «Цифровой цех — ремонты и ТО». В разделе «Цех» выберите станок на карте или в списке оборудования. В карточке видны инвентарный номер, состояние и срок следующего ТО.
4. Для первого знакомства пройдите шаги 2–5 на одном компьютере. Переключатель «Демонстрационная роль» позволяет по очереди выполнить действия заявителя, исполнителя и ответственного. Данные хранятся в `%LOCALAPPDATA%\PrintWorks` текущего пользователя Windows. При обновлении приложение использует существующие данные.

## 2. Создайте заявку

1. Выберите роль **«Заявитель»**. На карте откройте карточку станка и нажмите **«Создать заявку»**. Другой путь — раздел **«Заявки» → «Новая заявка»**.
2. Проверьте оборудование, выберите вид работы и срочность. В поле «Описание» напишите, что произошло. Например, «При подаче листа машина останавливается».
3. Нажмите **«Создать»**. Откройте карточку в разделе «Заявки» и запомните номер. По нему можно следить за ремонтом. Если выбрать срочность **«Авария»**, станок получит красный индикатор на карте, а руководитель увидит уведомление в разделе «Сообщения».

## 3. Возьмите заявку в работу

1. Переключитесь на **«Исполнитель»**, откройте «Заявки», выберите нужный номер и нажмите **«Взять в работу»**.
2. Выберите **«Диагностика»**, если сначала нужно установить причину неисправности, или переходите в **«Ремонт»**. Чтобы оставить запись для смены, нажмите «Добавить комментарий». Ход работ виден в журнале заявки.
3. Если нужны детали, выполните шаг 4. Если можно закончить ремонт без них, переходите к шагу 5.

## 4. Запросите и получите запчасти

1. **Исполнитель** в карточке заявки нажимает «Запросить запчасть», выбирает деталь и количество. Имеющиеся детали резервируются, недостающее количество появляется в разделе «Склад».
2. **Закупки** открывают «Склад», выбирают недостающую позицию в потребностях по заявкам и указывают «Дата поставки». Если ремонт нужно приостановить, исполнитель выбирает «Ожидание запчастей» и вводит причину. Для этого у всех недостающих позиций должны быть даты поставки.
3. **Кладовщик** регистрирует фактическое «Поступление» на складе. Когда весь комплект зарезервирован, ожидающая заявка автоматически возвращается в ремонт.
4. При передаче деталей исполнителю кладовщик выбирает потребность и нажимает **«Подтвердить выдачу»**. Для передачи ремонта на приёмку нужно выдать все запрошенные детали.

## 5. Сдайте и примите работу

1. **Исполнитель** переводит заявку из ремонта на приёмку кнопкой **«Передать на приёмку»**. Укажите причину отказа оборудования или основание для ТО, выполненные работы, заменённые детали при наличии и трудозатраты в часах. Число часов должно быть больше нуля. Нажмите «Передать».
2. **Ответственный** открывает заявку из раздела «Заявки» или из уведомления в «Сообщениях». Если результат устраивает, нажимает **«Принять работу»**. Заявка закрывается.
3. Если нужна доработка, ответственный нажимает **«Вернуть в ремонт»** и указывает причину. Исполнитель увидит её в карточке и после доработки повторит передачу на приёмку.

## 6. Настройте плановое ТО

1. Выберите роль **«Ответственный»**, откройте раздел **«ТО»**, выберите станок и нажмите **«Изменить график»**.
2. Заполните регламентные работы, выберите периодичность и интервал. Для дней или месяцев задайте следующую дату. Для моточасов или циклов задайте порог и обновляйте фактические значения через **«Внести показания»**.
3. По умолчанию интервал составляет 30 дней. Программа проверяет сроки при запуске, после сохранения изменений и каждую минуту работы. За неделю и за день до календарного срока появляются напоминания. При достижении срока или порога программа создаёт заявку на ТО.
4. Проведите её через выполнение и приёмку, как в шагах 3–5. После приёмки программа рассчитает следующий срок или порог от фактического выполнения.

## 7. Подключите остатки из Excel

1. Подготовьте книгу по образцу [Пример-остатков.xlsx](Пример-остатков.xlsx). В первой непустой строке первого листа должны быть заголовки **Артикул**, **Наименование** и **Остаток** в любом порядке. Остаток — целое число от нуля.
2. В роли **«Кладовщик»** откройте **«Склад» → «Подключить Excel с остатками»** и выберите книгу. Если её обновляют через общую папку, используйте постоянный путь.
3. Проверьте остатки в разделе «Склад». Книга считывается при подключении, при запуске приложения и каждую минуту, пока оно открыто. Неизменённая книга пропускается. Чтобы обнулить позицию, укажите явный ноль. У отсутствующих в книге артикулов сохраняются прежние остатки.
4. Если строка ошибочна или остаток меньше действующего резерва, программа покажет причину и сохранит прежние данные. Исправьте книгу. После успешного импорта запас распределяется по ожидающим заявкам.

## 8. Принимайте заявки через MAX

**Запуск.** Закройте ранее запущенный PrintWorks и откройте `Start-Max.cmd` из распакованного комплекта. Введите через запятую числовые MAX ID сотрудников, затем токен бота в скрытом поле. Оставьте открывшееся приложение запущенным. Состояние подключения видно в заголовке окна. Для этой версии нужен бот без активной webhook-подписки и без другого процесса, который получает его обновления.

**В общем чате цеха**

1. Добавьте бота в групповой чат MAX. Сотрудник из списка допущенных отправляет `/new`.
2. Бот по очереди запросит инвентарный номер станка, номер приоритета и описание. Каждый раз выбирайте **«Ответить»** на последний вопрос бота, адресованный вам. Так несколько сотрудников могут одновременно оформлять заявки в одном чате.
3. Бот пришлёт номер заявки в тот же чат. Исполнитель откроет её в разделе «Заявки» приложения и продолжит с шага 3.

**В личных сообщениях** сотрудник открывает диалог с ботом, отправляет `/new` и последовательно вводит те же три ответа. Команда `/my` в личке показывает статусы последних 12 заявок этого сотрудника. В группе бот подскажет, где их посмотреть. Команда `/cancel` отменяет незавершённый ввод в текущем чате.

Версия 0.3 принимает текстовые обращения. Обработка проверялась на тестовых сообщениях. Подробности подключения — в [инструкции MAX](MAX-README.md).

## Сборка и проверка

Готовый EXE доступен по ссылке в начале страницы. Для пересборки из исходников откройте PowerShell в распакованной папке и выполните `.\build.ps1 -Test`. Скрипт использует компилятор .NET Framework 4.x и запускает самопроверку.
