# Общий чат цеха

Запустите Start-Max.cmd с токеном бота и ID сотрудников. Добавьте бота в нужный групповой чат MAX. Допущенный сотрудник пишет /new. Для ввода номера станка, приоритета и описания каждый раз выбирает «Ответить» на последний вопрос бота, адресованный лично ему. Бот подтверждает регистрацию в том же чате. Номер появляется и в открытом приложении PrintWorks. /cancel отменяет оформление в текущем чате.

Сотрудники могут одновременно оформлять разные заявки. Переписка каждого сотрудника с ботом в личке и в разных группах обрабатывается отдельно. В группе /my подсказывает, где узнать статус; полный список сотрудник получает в личке.

# Бот MAX · тестовая сборка PrintWorks

Распакуйте весь архив. Закройте ранее запущенный PrintWorks. Дважды нажмите Start-Max.cmd, введите числовые MAX ID допущенных сотрудников и токен своего бота. Токен вводится скрыто. Держите открывшееся приложение запущенным. Для обычной работы без бота открывайте PrintWorks.exe. Это обновлённый клиент для локальной базы версии 0.2. Для испытания на копии используйте отдельный профиль Windows.

В личном диалоге с ботом отправьте /new, инвентарный номер станка, номер приоритета и описание. Ответ содержит номер заявки. Команда /my показывает текущие статусы последних 12 заявок отправителя. Команда /cancel сбрасывает незавершённый ввод. При аварийном приоритете станок меняет состояние на карте, руководитель получает уведомление внутри PrintWorks.

Программа обрабатывает сообщения допущенных ID. Для начала диалога сотрудник должен открыть бота в MAX. В этой версии поддерживаются текстовые обращения. При повторной доставке события заявка сохраняет прежний номер; после сетевого сбоя подтверждение может прийти повторно.

Для тестового подключения нужен бот без активной webhook-подписки и других процессов long polling. В заголовке окна показывается состояние соединения. Для постоянной эксплуатации предусмотрите переход на webhook. Проверка версии выполнена на тестовых сообщениях без подключения к аккаунту предприятия.

Документация MAX: https://dev.max.ru/docs-api/methods/GET/updates
